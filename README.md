# Retail Demand Forecasting & Inventory Optimization

Time-series forecasting platform for retail demand prediction using the M5 (Walmart) dataset.

## Tech Stack
- Python, SQL
- Google BigQuery (Data Warehouse)
- dbt (Data Transformation)
- Facebook Prophet, LightGBM (Forecasting)
- Streamlit (Dashboard)

## Structure
- `etl/` — data loading and quality checks
- `dbt_project/` — data transformation models
- `forecasting/` — Prophet and LightGBM models
- `dashboard/` — Streamlit app
- `notebooks/` — EDA
